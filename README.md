# ナナエビちゃん（nana_ebi-scheduler）

個人運用のAI秘書エージェント「ナナエビちゃん」。ベースは公開リポジトリ（GOROman/nullevi03、ナルエビちゃん三世＝Claude CodeをTelegram Bot経由で常時稼働させる極小ラッパー）。人間の確認を起点に、日々の大量対話を通じて信頼を積み上げ、段階的に自律範囲を広げる「育成型」エージェント。当面の目標はスケジュール管理する秘書AIエージェント。

boot.sh は GOROman/nullevi03 の boot.sh を参考にしています。https://github.com/GOROman/nullevi03/blob/main/boot.sh
