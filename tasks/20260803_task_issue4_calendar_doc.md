# Task：Issue #4 Google Calendar MCP疎通確認手順書の作成

起点：計画/naruebi_kilo_implementation_plan.md#4/採用

## 前提（重要）

Google Calendar公式remote MCPサーバーへのOAuth設定は、現時点では
まだ完了していません（人間・Claude Code側の設定作業が未了）。

したがって今回のtaskは、実際の疎通確認そのものではなく、
**OAuth設定完了後に弘晃さんが実施するための確認手順書の作成のみ**を
依頼します。コードの新規実装は発生しません。

実際の疎通確認（手順書に沿った動作確認）は、OAuth設定完了後に
弘晃さん側で実施します。Kilo Codeへの依頼範囲には含めません。

## やること

1. Telegram経由で自然文（例：「明日の予定を教えて」「来週の予定は？」）を
   投げたときに、Claude CodeがGoogle Calendar MCP経由で正しく応答できるかを
   確認するための手順書を作成する（docs/配下、例：docs/calendar_mcp_verification.md）
2. 以下3種類それぞれについて、確認すべきケースを洗い出す
   - 予定の照会（例：日付指定・期間指定・キーワード検索での問い合わせ）
   - 予定の登録（例：日時・タイトル・場所の指定、繰り返し予定、
     曖昧な日時表現「来週の月曜」等の解釈）
   - 予定の変更・削除（例：既存予定の時刻変更、キャンセル、
     該当予定が複数ある場合の曖昧さの扱い）
3. 各ケースについて「入力（Telegramに投げる文面）」「期待される動作」
   「確認方法（Google Calendar側で目視確認する項目）」を手順書に明記する
4. OAuth未設定の現時点では実行しないこと（手順書の作成のみ）

## 完了条件

- [ ] docs/calendar_mcp_verification.md が作成されていること
- [ ] 照会・登録・変更（削除含む）の3種類それぞれについて、
      具体的な確認ケースが列挙されていること
- [ ] 各ケースに入力文面・期待動作・確認方法が明記されていること
- [ ] Work_Reportを作成すること（このtaskでは実際の疎通確認は
      行っていない旨を明記する）

## 今回のtaskに含めないこと

- 手順書に基づいた実際の疎通確認の実施（OAuth完了後、弘晃さんが実施）
